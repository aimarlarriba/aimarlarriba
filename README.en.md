### 🚀 Featured Projects

#### 📊 Data Science, NLP & Machine Learning

* **[WhatsApp vs Telegram NLP & Business Intelligence](https://github.com/aimarlarriba/whatsapp-vs-telegram-nlp)**  
  End-to-end Natural Language Processing pipeline analyzing user sentiment and engagement patterns. Features Latent Dirichlet Allocation (**LDA**) topic modeling, coherence score ($C_v$) optimization, sentiment mining with **local LLMs (Gemma 2)**, and executive dashboards in **Tableau**.

* **[MNIST Unsupervised Clustering & Latent Space](https://github.com/aimarlarriba/MNIST_Clustering)**  
  Experimental unsupervised benchmarking on the normalized MNIST 784D pixel space. Combines spectral dimensionality reduction with **PCA**, partitional (**K-Means**) and probabilistic (**GMM**) clustering, optimal bijective cluster-to-class alignment via the **Hungarian Algorithm** (*Kuhn-Munkres*), and decoupled out-of-sample inference.

* **[AutoML Classification Engine](https://github.com/aimarlarriba/automl-classification-engine)**  
  Modular model governance and automated experimentation framework. Supports systematic hyperparameter sweeps across multiple classifier families (KNN, Random Forest, Naive Bayes) decoupled via JSON configuration, tracking tournament metrics reproducibly.

#### 💻 Software Engineering, Backend & Systems

* **[Azure Nebulas — Project Management & AI Governance Case Study](https://github.com/aimarlarriba/azure-nebulas-project-management)**  
  Empirical case study on Software Project Management and Generative AI-assisted engineering at UPV/EHU. Features Agile tracking via **OpenProject**, **Planning Poker** estimations, **53.75%** budget cost optimization (€1,645.40 saved), 10-point formal risk management matrix, and full 26-page academic report.

* **[Pokédex Ecosystem & Resilient Data Sync](https://github.com/aimarlarriba/pokedex-flask-manager)**  
  Modular full-stack web platform built with Python and **Flask** implementing the **Application Factory** and **Blueprints** patterns. Features SQLite relational storage with an **auto-healing** synchronization engine querying the public PokeAPI, recursive evolution trees, and an automated Pytest test suite with **GitHub Actions CI/CD**.

* **[eGela2Dropbox — Moodle to Cloud Synchronizer](https://github.com/aimarlarriba/eGela2Dropbox)**  
  Desktop automation utility in Python (**Tkinter**) for streaming course materials between university virtual campuses (**Moodle LMS**) and **Dropbox**. Implements session-authenticated web scraping with **BeautifulSoup**, streamed transfers, and an RFC-compliant **native OAuth 2.0 flow** on ephemeral TCP sockets (`localhost:8070`).

* **[KittyBoom — Retro Java Arcade Game](https://github.com/aimarlarriba/KittyBoom)**  
  Desktop Bomberman arcade game developed in pure Java with Swing. Architected with strict **MVC** separation and classic **GoF design patterns** (**Observer** for board state rendering, **Factory Method** for entity instantiation, and **Strategy** for block and bomb behavior).

* **[Frequency Analysis Cryptanalysis CLI](https://github.com/aimarlarriba/frequency-analysis-cipher-cli)**  
  Interactive terminal REPL for heuristic cryptanalysis of monoalphabetic substitution ciphers. Based on Spanish letter frequency distributions (RAE/Cervantes corpus), built with **zero external dependencies**, and verified with multi-version CI/CD pipelines.
